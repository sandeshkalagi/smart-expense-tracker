# Smart Expense Tracker

A full-stack web application to track and analyze daily expenses.

## Features
- Add expenses
- Delete expenses
- Category-wise breakdown
- Monthly analytics
- Interactive charts

## Tech Stack
Frontend: HTML, CSS, JavaScript, Chart.js  
Backend: Java, Spring Boot, REST API  
Database: H2
